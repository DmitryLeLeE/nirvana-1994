# Nirvana Memorial — фан-сайт в стиле 1994 года

Личный фан-сайт памяти Курта Кобейна и группы Nirvana, сделанный **как веб-страница 1994 года**:
таблицы, `<center>`, `<marquee>`, `<blink>`, счётчик «вы посетитель №…», гостевая книга,
«Under Construction», «Best viewed in Netscape Navigator 2.0».

Адрес: <https://dmitrylelee.github.io/nirvana-1994/>

## Технологии

- Чистый HTML + один `style.css`, без сборщиков и фреймворков.
- Нарочито примитивные приёмы 1994 года: Times New Roman и Courier New, синие ссылки,
  bevel-рамки (`inset`/`ridge`), тег `<marquee>`, анимированные GIF.
- Пиксель-арт — собственный (SVG): портрет, гитара, ангел, свеча, сердце, кассета, микрофон, Сиэтл, фланель.
- GIF-баннеры, кнопки 88×31, текстуры, favicon и og-image генерируются **`tools/gen_assets.py`**
  (Python + Pillow, детерминированно). Полный список файлов — в коде скрипта.
- Фото — свободные, с Wikimedia Commons (горячие ссылки с атрибуцией на странице Media).
- Видео — официальные клипы Nirvana с YouTube (embed 320×240).

## Деплой

- GitHub Pages, ветка `main`, корень репозитория.
- Пуш: `git push origin main` (правило проекта: каждое изменение сразу коммитится и пушится).

## О содержании

Страница «Death & Legacy» — факты и контекст. Способ и записка упомянуты **только как
констатация факта** (без пошаговости; полный текст записки не публикуется — это личный документ).
Романтизация смерти описана как факт культуры, в котором сайт не участвует.

## Фавикон и соц-превью

- `favicon.ico` — пиксельная свеча (16/32 px), подключена на всех 15 страницах.
- `og-image.png` (1200×630) — ретро-баннер «NIRVANA · IN MEMORY OF KURT COBAIN · 1967–1994».
- OpenGraph/Twitter-меты (`og:title`, `og:description`, `og:image`, `twitter:card`) — на всех страницах,
  `og:image` указывает на живой URL GitHub Pages.

## Структура

```
index.html … links.html  — 15 страниц (список выше)
style.css                — весь стиль, один файл
assets/                  — вся графика (генерируется и рисуется вручную)
tools/gen_assets.py      — генератор графики (Python + Pillow)
robots.txt
favicon.ico · og-image.png
```

## Правовые примечания

- Частный фан-сайт, некоммерческий, без связи с группой, лейблами и наследниками Курта Кобейна.
- Тексты песен не воспроизводятся — только названия треков и пересказ смысла своими словами.
- Фотографии — свободные (Wikimedia Commons), каждая с ссылкой на страницу-источник.
- Видео — официальные клипы через YouTube embed.
