# NIRVANA · памяти Курта Кобейна

> a grunge fanzine · est. 1994 · in memory of Kurt Cobain

Этот сайт — не энциклопедия и не справочник. Это благодарственное письмо, которое
вышло из-под контроля.

Я сделал его так, как делали сайты в 1994-м: руками, в блокноте, без сборщиков
и фреймворков. Times New Roman и Courier New. Таблицы и `<center>`. Мигающие баннеры
«UNDER CONSTRUCTION», счётчик «вы посетитель №…», гостевая книга, веб-кольцо и пара
фейковых баннеров-реклам — потому что тогда они были повсюду, и без них сайт не дышит.

Внутри — всё, за что я люблю Нирвану: группа и её история, дискография с трек-листами,
песни с разбором смысла (тексты не печатаю — они и так у всех в голове), цитаты Курта,
его семья, сцена Сиэтла, «клуб 27» и страница о 5 апреля 1994 года.

Пройдись по страницам. Кликни на всё. Почитай исходник. В веб-кольце на главной спрятана
секретная страница — найдёшь её, если ты из тех, кто кликает на всё.

*— сделано с любовью, в память о Курте Кобейне*

## Что внутри

Шестнадцать страниц: главная, группа, сцена Сиэтла, таймлайн, дискография, Курт, семья,
смерть и наследие, «клуб 27», песни, цитаты, медиа, фотогалерея, гостевая, источники —
и одна секретная.

Вся графика своя: GIF-шапки у каждой страницы, кнопки 88×31, мигающие бейджи,
баннеры-рекламы, анимированное пламя. Фото и обложки альбомов — с Википедии и Wikimedia
Commons, включая настоящую гитару Курта и «ангела» In Utero из музея MoPOP. Видео —
официальные клипы.

## Для тех, кто забрёл сюда технически

- Сайт статический: HTML + один `style.css`, ветка `main`, GitHub Pages:
  <https://dmitrylelee.github.io/nirvana-1994/>
- Вся GIF/PNG-графика генерируется одним скриптом: `python tools/gen_assets.py` (Python + Pillow).
- Проект частный и некоммерческий, без связи с группой, лейблами и наследниками.
