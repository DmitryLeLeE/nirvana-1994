# Nirvana Memorial — фан-сайт в стиле 1994 года

Личный фан-сайт памяти Курта Кобейна и группы Nirvana, сделанный **как веб-страница 1994 года**:
таблицы, `<center>`, `<marquee>`, `<blink>`, счётчик «вы посетитель №…», гостевая книга,
«Under Construction», «Best viewed in Netscape Navigator 2.0».

Адрес: <https://dmitrylelee.github.io/nirvana-1994/>

## Технологии

- Чистый HTML + один `style.css`, без сборщиков и фреймворков.
- Нарочито примитивные приёмы 1994 года: Times New Roman и Courier New, синие ссылки,
  bevel-рамки (`inset`/`ridge`), тег `<marquee>`, анимированные GIF.
- Пиксель-арт — собственный (SVG): портрет, гитара, ангел, свеча, сердце, кассета, микрофон.
- GIF-баннеры и тайловая текстура фона генерируются Python + Pillow (скрипт в истории коммитов).
- Фото — свободные, с Wikimedia Commons (горячие ссылки с атрибуцией на странице Media).
- Видео — официальные клипы Nirvana с YouTube (embed 320×240).

## Деплой

- GitHub Pages, ветка `main`, корень репозитория.
- Пуш: `git push origin main` (правило проекта: каждое изменение сразу коммитится и пушится).

## О содержании

Страница «Death & Legacy» — только факты и контекст: **без описания способа, без полного текста
прощальной записки, без романтизации**. Это принципиально и не обсуждается.
